# Project Resources

`RESOURCE_ADOPTIONS.json` records only resources actually adopted by this project, including Vault capability/resource ID, pinned version/hash, local integration point, reason, constraints and verification gate.

Search this record before rebuilding. When a new local tool may help another project, add a candidate to `40-State/RESOURCE_CANDIDATES.json`. If the Vault is available, submit its exact files through `vault.py propose`; do not copy source directly into verified first-party content.
